# 协作者画像与协作方式

记录一些只有我和搭子才知道的协作习惯，供以后对暗号。

搭子全程用中文沟通，指令极短，经常一句话就切一个新需求，不写需求文档也不开评审会；但每个点都盯得很紧，反馈来得快、改得也快。功能上线前喜欢自己动手验证：不是看测试报告，而是亲自造一批语料数据、用真实界面操作、观察真实结果，这次拿一批私有文档去测向量召回也是同一个路数。

沟通里出现过几条明确的否决：表格搜索不要加"命中摘要"列，因为"不要破坏已有的表格结构"；管理面板的工具栏必须一行放下。也出现过几次越过我建议的拍板，比如表格搜索的范围他选了"所有可读文档"，我原本推荐的是限定创建者——这种时候直接按他说的做，不留尾巴。

项目是净室实现的：和另一个同类老项目只有一处图表渲染流程是承认的移植，其余全部从零写，任何代码都不能从那边拷贝。仓库在 GitHub 上，提交说明用中文一句概括要点，批次完成后再推送，推送节奏由搭子口头控制。
